# Third-party tools and asset boundaries

Original toolkit source, templates and authored notes are GPL-3.0; see LICENSE. Preserve upstream notices. This repository grants no rights to games, models, textures or animations referenced in case studies. Character names identify experiments, not included art or endorsements.

| Dependency | Publisher | Handling |
| --- | --- | --- |
| Darktide SDK / compiler / addon | https://github.com/fviuff/Darktide-SDK | GPL-3.0, downloaded locally using pinned digest |
| limn | https://github.com/manshanko/limn | MIT OR Apache-2.0, downloaded locally |
| MikuMikuRig | https://github.com/XiaoFFGe/MikuMikuRig | GPL-3.0, pinned source downloaded locally |
| Blender | https://www.blender.org/ | GPL, separate installation |
| DML / DMF | https://github.com/Darktide-Mod-Framework | Original distributions, no binaries vendored |
| Custom Assets API / patcher | https://github.com/fviuff/darktide-mods/tree/main/Custom-Assets-patcher | No root license declared in inspected upstream; not redistributed |
| Bitsquid Blender Tools | https://gitlab.com/qasikfwn/bitsquid-blender-tools | Optional legacy route; not vendored or relicensed |
| MMD Tools | https://github.com/MMD-Blender/blender_mmd_tools | Optional import route, not vendored |
| Oodle | User's licensed Darktide installation | Proprietary; local setup cache only, never distributed |

Character Material Bridge and other import plugins may have separate restrictions. They are excluded; the baseline does not require them. Users supply authorized plugins or develop supported bake/conversion routes. Optional Python packages retain their own licenses. Generated mod distributors must verify source-art redistribution rights separately from this toolkit's license.
